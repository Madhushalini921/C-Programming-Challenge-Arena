# 🎮 C Programming Challenge Arena

C Programming Challenge Arena is a C-based console application containing 10 interactive mini-games designed to improve programming, logical thinking, and problem-solving skills while providing an enjoyable gaming experience.

## ✨ Features

🎯 C Programming Quiz
🔢 Guess The Number
✊ Rock Paper Scissors
❌ Tic Tac Toe
🦸 Superhero Rescue Mission
🔤 Hangman
🐍 Snake and Ladders
💎 Treasure Hunt Adventure
🏰 Castle Escape
🚀 Space Adventure

## 🛠️ Technologies Used

C Programming
GCC Compiler
Standard C Libraries
Modular Programming

## 🚀 How to Run

### 1. Clone the repository

```bash
git clone https://github.com/your-username/C-Programming-Challenge-Arena.git
```

### 2. Open the project

```bash
cd C-Programming-Challenge-Arena
```

### 3. Compile the project

```bash
gcc *.c -o arena
```

### 4. Run the application

```bash
arena.exe
```

## 🎯 Purpose

C Programming Challenge Arena provides a fun and interactive way to practice C programming concepts through multiple mini-games while improving logical thinking, problem-solving, and programming skills.
